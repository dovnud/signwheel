# SignWheel

SignWheel (signwheel.com) is a free astrology site that runs entirely in the visitor's browser. No account, no server chart calls: the chart is calculated on the page itself.

What is here:

- A birth chart tool with a full plain-words reading, saved and shared by link with no sign-up
- A compatibility tool for two charts, with a verdict in words and a share card
- A moon phase page and a live ephemeris page
- A reading library: planets in signs, planets in houses, and the twelve signs
- 171,811 birth places from the GeoNames world list (CC BY 4.0), loaded in small pieces so phones stay fast

The chart maths is checked against NASA JPL reference values (DE440). Worst gap across the proof set: the Moon at 3.12 arc-minutes, no wrong signs.

Static HTML, CSS and JavaScript. No framework, no build step for the pages themselves. The library pages are generated by tools/build-library.js and the place list by tools/build-places.js.
